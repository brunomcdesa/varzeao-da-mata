# Carreira persistente entre Temporadas

O Time e o OVR de cada Jogador continuam de uma Temporada para a seguinte, formando uma Carreira. Escolhemos isso em vez de resetar o OVR ou zerar tudo porque a Carreira dá ao seguidor um motivo para acompanhar a Liga indefinidamente e voltar a cada Temporada. Depois que existirem Carreiras acumuladas, um reset seria percebido como perda pelo público, então tratamos a decisão como praticamente irreversível.

## Consequences

- Trocar de Time só é possível entre Temporadas, numa janela de "transferências".
- O equilíbrio do OVR a longo prazo passa a importar (ver ADR-0004).
